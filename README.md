# 📊 Consumer Finance Complaint Tracker

## 🧐 Overview
This project is an **interactive financial complaints dashboard** built using **Tableau**. It provides a detailed visualization and analysis of consumer complaints in the financial sector. The dashboard categorizes complaints by **issue type, media source, financial product, and geographical location** to help stakeholders, such as banks and financial institutions, identify trends and enhance customer service.

## 📌 Dashboard Highlights

### **Key Metrics**
- **📈 Total Complaints:** 75,513 recorded complaints.
- **⏳ Timely Response Rate:** 98.1% of complaints received a response within the expected time frame.
- **🛑 Pending Complaints:** Only **0.37%** (283 complaints) remain unresolved.
- **💸 Resolution at No Cost:** 84.5% of complaints were resolved without monetary compensation.
- **⚖️ Dispute Rate:** 9.8% of complaints were escalated as disputes.

### **Complaint Distribution & Insights**
#### **📝 By Issue**
- **Managing an Account**: The most common complaint type.
- **Deposits & Withdrawals**: A significant portion of complaints involve banking transactions.
- **Trouble Making Payments** and **Billing Disputes** are among the top issues reported.

#### **📧 By Media Source**
- **Web Submissions:** 50.37% of complaints were filed online.
- **Referral Complaints:** 29.52% came through third-party referrals.
- **Phone and Postal Mail Complaints** also contribute to a smaller percentage.

#### **💳 By Product Type**
- **Credit Cards:** Most complaints (19,176 complaints, 25.36%).
- **Checking & Savings Accounts:** 13,436 complaints (17.79%).
- **Mortgages:** 12,470 complaints (16.51%).

#### **🌍 By State**
- **Hex Map Visualization:** Complaints are displayed per state, with darker shades indicating higher complaint volumes.
- The highest number of complaints were recorded in **California and Texas**.

#### **📊 Customer Dispute Analysis**
- **40% (31,203 complaints)** were categorized under customer disputes.
- A **pie chart** visualization helps illustrate dispute distribution.

## 🚀 Installation & Setup
Follow these steps to set up and explore the dashboard:

1. **Clone the Repository**:
   ```sh
   git clone https://github.com/yourusername/financial-complaints-dashboard.git
   ```

2. **Open the Tableau Workbook**:
   - Ensure you have **Tableau Desktop** installed.
   - Load the `.twb` or `.twbx` file in Tableau.

3. **Connect to the Dataset**:
   - The dataset is included in the repository (CSV/Excel format).
   - Ensure the data source is linked correctly in Tableau.

4. **Explore the Dashboard**:
   - Interact with various filters and visualizations.
   - Analyze trends, identify insights, and generate reports.
